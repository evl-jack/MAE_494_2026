# Local reference-resolution audit

This is a numerical audit of the deliberately selected development failure, group 603. It introduces no training, new rollout policy, production-controller change, final-test query or new independently sampled encounter. The original models and all previous result files remain unchanged. The protocol fixes three full-domain reference levels before new results: 129×129×96, 161×161×120 and 193×193×144, each over [-2,2]² with periodic relative heading.

The solver implementation, physical parameters, obstacle rule and CFL coefficient remain unchanged. Spatial, heading and CFL-limited time discretization refine together. This does not isolate one source of numerical error. Twenty-one direct solution time planes are retained during computation; only queried values and coefficients are saved afterward. No new scheme, cropped domain or adaptive refinement is substituted. Each completed level is saved separately, and explicit resume can reuse its verified outputs if interrupted.

The first check rebuilds the 129-grid reference and must reproduce saved fine values and switching coefficients on the fixed early unassisted trajectory to within 1e-12. The trajectory is the canonical pose of the previous 4C baseline, sampled every .005 s through .1 s. Identical physical states and remaining times are queried across all grids. The audit does not resimulate trajectories using refined policies, so it separates reference changes from path changes.

At each fixed early state, evader heading offsets from -.2 to +.2 rad are sampled at .002-rad spacing. Only the evader heading changes; both positions and the pursuer heading stay fixed. The state is then reduced to relative coordinates. This is the instantaneous control direction in joint coordinates, not a common global rotation. All resulting relative configurations and their physical dependency bounds stay inside the original numerical domain.

The main switching estimate is the existing one: central spatial/periodic-heading grid derivatives, then spatial trilinear and temporal linear interpolation. For g=(gx,gy,gpsi), its evader coefficient is `ry*gx-rx*gy-gpsi`; the maximizing turn is `3*sign(coefficient)`. The minimizing pursuer uses `-3*sign(gpsi)`. This derivative estimate is distinct from differentiating the interpolated scalar values.

At the initial state, the value interpolant is also queried at physical heading perturbations ±1e-5 and ±1e-6 rad to estimate its derivative. Left and right secants at .002, .005, .01, .02 and .04 rad expose scale sensitivity and possible local nonsmoothness. These are derivatives/secants of the approximate interpolated numerical value, not exact derivatives of the true game value. Agreement between two numerical estimators does not establish a rigorous error bound.

The initial heading cut is queried in the unchanged 4C and 3D_Long networks at all four existing poses. Their weights do not receive updates or parameter gradients. The local numerical audit uses the canonical pose because equivalent representations reduce to the same physical relative state. Raw path/neighborhood queries and source/input hashes are saved so the comparisons can be checked independently.

Reports distinguish stability of the control sign from convergence of the coefficient magnitude, and report disagreements across grids or derivative estimators directly. Three finite levels cannot prove convergence or an exact optimal switching surface. Any zero-crossing locations describe the fixed sampled/interpolated neighborhood, not certified state-space boundaries. The audit executes as a managed process with the main project interpreter and is viewed in VS Code after completion.
